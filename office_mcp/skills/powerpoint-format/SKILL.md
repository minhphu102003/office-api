# PowerPoint Formatting Standards

Professional formatting guidelines for .pptx presentations. Apply these standards when creating templates or instructing users.

## Font

| Element | Font | Size | Weight |
|---------|------|------|--------|
| Slide title | Arial / Calibri | 36-44pt | Bold |
| Subtitle | Arial / Calibri | 28-32pt | Semi-bold |
| Body text | Arial / Calibri | 24-28pt | Regular |
| Captions | Arial / Calibri | 18-20pt | Regular |
| Footnotes | Arial / Calibri | 14-16pt | Regular |

- Use sans-serif fonts (Arial, Calibri, Helvetica) — clearer on projected screens
- Maximum 2 font families per presentation
- Use font weight (bold/semi-bold/regular) for hierarchy within one family
- Test readability from 6 feet (2 meters) away
- Avoid serif fonts for body text — they blur on screens
- Minimum 24pt for any readable content

## Colors

- Maximum 3-5 colors in palette
- High contrast: dark text on light background (or vice versa)
- Ensure WCAG 4.5:1 contrast ratio minimum
- Use brand colors consistently
- Avoid bright colors on white backgrounds (hard to read)
- Test colors on projector before finalizing
- Common schemes:
  - Dark navy (#1F3864) header + white text
  - Charcoal (#333333) body + light gray (#F2F2F2) background
  - Single accent color for highlights

## Layout Rules

| Rule | Description |
|------|-------------|
| 5x5 rule | Max 5 words per line, 5 lines per slide |
| 10/20/30 rule | Max 10 slides, 20 minutes, 30pt minimum font |
| 5/5/5 rule | Max 5 words/line, 5 lines/slide, 5 text-heavy slides in a row |
| One idea | One key message per slide |

- Use Slide Master (View > Slide Master) for consistent formatting
- Apply consistent margins and padding across all slides
- Use grid systems for alignment
- Keep bullet points to 4-5 maximum per slide

## Spacing & Alignment

- **Margins:** 0.5-1 inch on all sides (action safe area at 95%)
- **Line spacing:** 1.2-1.5 for body text
- **White space:** Leave breathing room — don't fill every inch
- **Alignment:** Left-align body text; center titles
- Consistent position of recurring elements (logo, page number)

## Images & Graphics

- Use high-resolution images only (min 150 DPI)
- Consistent image style (photos vs illustrations — pick one)
- Anchor images to slide position (not text)
- Maintain aspect ratio when resizing
- Provide alt text for accessibility
- Avoid animated GIFs — distracting

## Charts & Tables

- **Charts:** Match brand colors; remove default gridlines; label directly
- **Tables:** Minimal borders; shaded header row; proper alignment
- Keep charts simple — one chart per slide
- Use consistent chart style throughout

## Animations & Transitions

- Minimal: Appear/Disappear only for build slides
- No fly-in, zoom, spin, or bounce effects
- Use On Click (not auto) to control pacing
- Same transition throughout (or no transition)
- Animate only when it adds clarity, never for decoration

## Slide Types

| Slide Type | Content Guidelines |
|------------|-------------------|
| Title slide | Logo, title, subtitle, date. Center-aligned |
| Section divider | Section title (36-40pt), optional subtitle |
| Content slide | Title 36pt, body 24-28pt, max 5 bullets |
| Data/Chart | Title + chart. Remove legend if direct labels suffice |
| Quote slide | Large quote text (32-36pt italic) + attribution |
| Closing | Thank you, contact info, CTA. Clean design |

## Best Practices

- Use Slide Master to ensure consistency — never format slides individually
- Keep text concise: keywords and phrases, not paragraphs
- Use visuals instead of text wherever possible
- Maintain same layout continuity frame to frame
- Review in Slide Show mode before presenting
- Save accessible PDF backup for distribution
- Keep file size manageable (compress images)
- Review spelling and grammar — errors look unprofessional on screen
