# Word Formatting Standards

Professional formatting guidelines for .docx documents. Apply these standards when creating templates or instructing users.

## Font

| Element | Font | Size | Weight |
|---------|------|------|--------|
| Body text | Times New Roman | 12pt | Regular |
| Heading 1 | Times New Roman | 18pt | Bold |
| Heading 2 | Times New Roman | 16pt | Bold |
| Heading 3 | Times New Roman | 14pt | Bold |
| Captions | Times New Roman | 10pt | Regular |
| Footnotes | Times New Roman | 10pt | Regular |

- Use serif fonts (Times New Roman, Georgia) for print documents
- Use sans-serif fonts (Arial, Calibri) for screen-only documents
- Maximum 2 font families per document
- Avoid decorative or script fonts for body text
- Use bold and italics sparingly for emphasis

## Page Setup

- **Margins:** 1 inch (2.54cm) all sides; 1.5 inch left margin if bound
- **Paper size:** A4 or US Letter (8.5 x 11 inch)
- **Page numbers:** Bottom center; Roman numerals for preliminary pages, Arabic for main body
- **Section breaks:** Between chapters or major sections

## Spacing

- **Line spacing:** 1.5 for business; Double (2.0) for academic; 1.15 for digital
- **Paragraph spacing:** 6-12pt after each paragraph
- **First-line indent:** 0.5 inch for academic paragraphs
- **Space before heading:** 18pt before H1, 12pt before H2/H3

## Alignment

- **Body text:** Justified (left-right aligned)
- **Headings:** Left-aligned; center for document title
- **Lists:** Left-aligned with consistent indent
- **Block quotes:** Left-indented 0.5 inch, single-spaced

## Colors

- **Body text:** Black (#000000)
- **Headings:** Dark blue (#1F3864) or Charcoal (#333333)
- **Maximum 3 colors** in the entire document (including accent)
- Ensure sufficient contrast (4.5:1 ratio minimum for WCAG compliance)
- Avoid colored body text; use color only for headings and accents

## Styles

- Always use Word Styles (Heading 1-3, Normal, Body Text) — never format manually
- Modify built-in styles rather than creating new ones
- Base Body Text on Normal with spacing adjustments
- Use linked styles for headings (paragraph + character)

## Tables

- Header row: Bold, shaded background (light gray or brand color)
- Alternate row shading for readability (banded rows)
- Borders: Minimal — top/bottom borders only for clean look
- Font: Same as body, 10-11pt for table content

## Headers & Footers

- **Header:** Document title or chapter name (optional)
- **Footer:** Page numbers, date, file path (if applicable)
- Different first page for cover pages

## Best Practices

- Use section breaks (not page breaks) between major sections
- Keep paragraph length to 4-6 lines maximum
- Use bullet lists for 3+ items; numbered lists for sequences
- Avoid underlining — use bold or italics instead
- Limit to 2-3 font sizes total
- Export to PDF when sharing externally to preserve formatting
- Review in Print Layout before finalizing
